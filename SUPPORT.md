# Support

- Usage questions and reproducible bugs: [GitHub Issues](https://github.com/Euraika-Labs/personal-assistant-memory-routing/issues)
- Security reports: follow [SECURITY.md](SECURITY.md)
- npm package: [@euraika-labs/personal-assistant-memory-routing](https://www.npmjs.com/package/@euraika-labs/personal-assistant-memory-routing)

Before opening an issue, run `pamr doctor` and `npm run check`. Remove prompts, recalled content, secrets, personal paths, and private provider data from diagnostics.
